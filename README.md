# Nexora

Nexora is a premium business website concept for a digital agency that helps local businesses grow through strategy, design, and online visibility.

## Features

- Modern Vite + React landing page
- Responsive marketing layout for services and lead generation
- Contact form that opens WhatsApp and email workflows
- Designed for GitHub Pages deployment

## Local development

```bash
cd nexora-labs/client
npm install
npm run dev -- --host 0.0.0.0 --port 4173
```

## Production build

```bash
cd nexora-labs/client
npm run build
npm run preview -- --host 0.0.0.0 --port 4173
```

## Deploy to GitHub Pages

```bash
cd nexora-labs/client
npm run deploy
```

This project is configured for the GitHub Pages project site URL:

https://abdulkhader20.github.io/nexora/
